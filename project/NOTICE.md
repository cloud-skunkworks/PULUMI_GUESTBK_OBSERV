# Third-party components

This package uses Pulumi, its Kubernetes provider, OpenTelemetry, TypeScript, esbuild, fflate, Node.js, Redis, and the Prometheus community monitoring chart and dependencies.

Exact npm versions and integrity values are in package-lock.json. Bundled application code retains dependency license comments. Review upstream licenses, including Redis 8, under your organization's software policy. Container images and Helm chart dependencies are obtained separately at deployment time.

The original package declared Apache-2.0 in package.json. This refactor preserves that declaration; ownership and legal approval remain with the repository owner.
