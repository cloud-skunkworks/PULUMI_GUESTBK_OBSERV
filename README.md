# PULUMI_GUESTBK_OBSERV

Release-candidate artifacts for the Pulumi Kubernetes Guestbook observability implementation.

## RC1 Artifacts

The RC1 package is available under `releases/RC1/`.

| Artifact | Purpose |
|---|---|
| `4iRDemo.zip` | Pulumi TypeScript implementation for Guestbook, Prometheus, Grafana, ServiceMonitor, dashboard, and docs. |
| `4iRDemo-DevOps-SRE-Runbook.zip` | Operator runbooks and validation scripts for local Kubernetes, AKS, EKS, and GKE. |

These files are intended for the DevOps SRE team to review, deploy in a controlled environment, and use as the RC1 implementation baseline.
